Getting started

Configuration

SolarCORE reads its settings from a file named .env in the project folder. Start from the example with copy .env.example .env. On a hosting platform such as Railway, enter the same names as the platform's environment variables instead; they take priority over the file.

Secrets stay out of Git .env contains passwords and API keys. It is ignored by Git and must never be shared. The examples on this page show empty values on purpose.

Application

SettingWhat it doesExample
APP_NAMEThe application's name.SolarCORE
APP_ENVdevelopment on your own computer, production on a real server. In development, a login code that cannot be emailed is shown on the page; production refuses the sign-in instead.development

Where the app is served

SettingWhat it doesExample
APP_BASE_PATHThe part of the address in front of every page. /solarcore/public for XAMPP (the default). / when SolarCORE has its own domain or subdomain. Write /, not a blank, for a root./solarcore/public
APP_URLThe full public address, including that prefix, with no slash at the end. Used for links in emails and for Google sign-in, so it must match the address people actually type.http://localhost/solarcore/public

Database

SettingWhat it doesExample
DB_HOSTThe PostgreSQL server.localhost
DB_PORTIts port. 5432 is PostgreSQL's default; use whatever you chose when installing it.5432
DB_DATABASEThe database name.solarcore_db
DB_USERNAMEThe database user.postgres
DB_PASSWORDThat user's password.

Organisation

Who this copy of SolarCORE belongs to. These three settings are the only change needed to run SolarCORE for a different company.

SettingWhat it doesExample
ORG_NAMEFull company name. Appears on PDF reports and in the assistant's answers."Company A"
ORG_SHORTShort name."Comp A"
ORG_ABOUTA few sentences the assistant may use to describe the company. Leave it blank and the assistant declines questions about the company instead of guessing."Company A installs…"

Outgoing mail

Email carries the login codes (every sign-in needs one), notifications, and Contact Us and client report messages. Inquiries and reports are always saved in SolarCORE as well, and emailed to MAIL_FROM_ADDRESS, which is treated as the company inbox.

SettingWhat it does
MAIL_DRIVERbrevo, smtp or none. Leave blank to pick automatically: Brevo if a Brevo key is set, otherwise SMTP if a mail host is set.
MAIL_FROM_ADDRESSThe sender address, and the company inbox. With Brevo it must be a sender you have verified in Brevo.
MAIL_FROM_NAMEThe sender name, e.g. "SolarCORE".
BREVO_API_KEYFor brevo: an API key from Brevo (SMTP & API → API Keys). Sends over HTTPS, so it works on hosts that block mail ports.
MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD, MAIL_ENCRYPTIONFor smtp. MAIL_ENCRYPTION is tls (port 587), ssl (port 465) or none.

Using Gmail (SMTP)

  1. Turn on 2-Step Verification for the Google account.
  2. Create an App Password under Google Account → Security → App passwords.
  3. Fill in the settings, using the App Password, not your normal password: 
    MAIL_DRIVER=smtp
MAIL_FROM_ADDRESS=yourcompany@gmail.com
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=yourcompany@gmail.com
MAIL_PASSWORD=
MAIL_ENCRYPTION=tls

To check the mail settings, the project includes scripts/send-test-email.php.

Login verification

SettingWhat it does
LOGIN_EMAIL_CODEon (default): every sign-in needs the emailed 6-digit code. off: an emergency switch only, for example if the mail provider is down. Leave it on.

A code is valid for 10 minutes and allows 5 tries. A new one can be requested after 60 seconds.

Continue with Google

SettingWhat it does
GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRETFrom Google Cloud Console: APIs & Services → Credentials → Create credentials → OAuth client ID → Web application. The consent screen needs the scopes openid, email and profile.
GOOGLE_REDIRECT_URIOptional. Defaults to APP_URL + /auth/google/callback. Register that exact address as an Authorized redirect URI in Google Cloud Console.

While these are empty, the Google button still shows and explains that Google sign-in is not set up yet.

AI assistant

The assistant works without these settings: it falls back to built-in, rule-based answers with plainer wording. Figures always come from the database either way.

SettingWhat it does
AI_ENABLEDtrue or false.
AI_PROVIDERgroq (hosted, has a free tier, works on servers) or ollama (runs a model on the same machine; local use only).
AI_MODELFor Groq, the recommended model is openai/gpt-oss-120b. For Ollama, e.g. llama3.1:8b. Providers retire models from time to time; check their current list.
GROQ_API_KEYA key from console.groq.com. Required when the provider is Groq.
OLLAMA_URLWhere Ollama listens, e.g. http://localhost:11434.

Photo storage

SettingWhat it does
PHOTO_STORAGE_PATHWhere uploaded photos are saved. On your own computer, leave the line commented out (the default folder is used); do not set it to an empty value. On a server, point it at a permanent folder or volume outside public/, e.g. /data/photos on Railway.

Map area

The map's starting point, zoom and allowed area are not in .env; they are in config/geo.php. The default view centres on the Philippines (12.8797, 121.7740) at zoom 6. Change it there to open the map on your company's service area. The form's map opens on your existing installations automatically.

A complete example

A local development setup with Gmail. Secrets are left empty here; fill them in your own .env.

APP_NAME=SolarCORE
APP_ENV=development
APP_BASE_PATH=/solarcore/public
APP_URL=http://localhost/solarcore/public

DB_HOST=localhost
DB_PORT=5432
DB_DATABASE=solarcore_db
DB_USERNAME=postgres
DB_PASSWORD=

AI_ENABLED=true
AI_PROVIDER=groq
AI_MODEL=openai/gpt-oss-120b
GROQ_API_KEY=

ORG_NAME="Company A"
ORG_SHORT="Comp A"
ORG_ABOUT="Company A installs and maintains solar systems in Santiago City and nearby areas."

MAIL_DRIVER=smtp
MAIL_FROM_ADDRESS=
MAIL_FROM_NAME="SolarCORE"
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=
MAIL_PASSWORD=
MAIL_ENCRYPTION=tls

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

LOGIN_EMAIL_CODE=on
