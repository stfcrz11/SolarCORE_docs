Using SolarCORE

Import and export

Bring many installations in at once from a spreadsheet, and take the list out for reports or GIS software. Both are for administrators and technicians.

Importing a spreadsheet

Open Installations → Import. An import has three steps, and nothing is saved until the last one.

  1. Upload a CSV file Start from Download CSV template if you are making a new sheet; it has the right columns and an example row. Upload your file and click Continue to preview. Up to 2,000 rows per file.
  2. Match the columns SolarCORE guesses which of your columns is which: "Site Name", "Lat" or "kWp" are recognised. Check the guesses, fix any that are wrong, then click Next step. If the file uses the template's exact column names, this step is skipped.
  3. Review and import Every row is shown as ready, duplicate or invalid, with the reason. Fix invalid rows in your spreadsheet and upload again, or import the ready rows now with Import installations.
All or nothing The ready rows are saved together. If anything goes wrong while saving, none of them are, so a failed import can simply be tried again without creating doubles.

Saving a CSV from Excel

Excel files (.xlsx, .xls) are not read directly. In Excel choose File → Save As → CSV UTF-8 (Comma delimited) (*.csv) and upload that file. These are all accepted:

  • comma-, semicolon- or tab-separated files (Excel in many regions saves "CSV" with semicolons);
  • Excel's UTF-8 files, so names like Peñablanca come through correctly;
  • blank lines, which are skipped.

Columns

ColumnRequiredAccepted values
installation_nameYesThe site's name, e.g. "Dela Cruz Residence".
client_nameYesThe owner's name. Imported installations are not linked to a client account; link them later on the installation's form.
addressYesStreet address.
barangay, municipality, provinceNoUsed for analytics by area and for search.
latitude, longitudeYesDecimal degrees, e.g. 16.6870 and 121.5480. Must be inside the Philippines.
installation_typeYeson-grid, off-grid or hybrid. Also "On Grid", "grid-tied", "standalone" and similar.
capacity_kwpYesA number above 0, with or without "kWp", e.g. 5.5 or 5.5 kWp.
installation_dateYesBest as YYYY-MM-DD. Other common formats, such as 03/03/2026 or March 3, 2026, are accepted. Impossible dates like 31 February are rejected.
statusYesawarded, under construction, operational, under maintenance, inactive or decommissioned. Common words work too: "active", "online", "repair", "retired"…
notesNoAnything else.

Duplicates

Uploading the same sheet twice would double every installation and every total, so each row is checked against the installations already in SolarCORE and against earlier rows of the same file.

ResultWhenWhat happens
DuplicateThe same name (ignoring capitals, spacing and punctuation) within 50 m or at the same address; or any record within 3 m, whatever its name.Skipped, unless you tick Import anyway for that row.
NearbyA different name within 25 m of an existing installation.A warning only; it is imported. Neighbouring houses really do both have panels.

Common reasons a row is invalid

  • Coordinates fall outside the Philippines: latitude and longitude are often swapped. Latitude is the smaller number, around 5 to 21.
  • Type must be one of: on-grid, off-grid, hybrid.
  • Capacity (kWp) must be a number greater than 0.
  • Installation date is missing, unreadable or not a real date.
  • A row whose cells are shifted, usually because of a stray quote mark (") in the sheet. Remove it and save the CSV again.

Exporting

On Installations, set any search and filters first, then open Export and choose a format. The export contains exactly what the list is showing.

FormatGood forContains
CSVExcel, Google Sheets, other systemsOne row per installation with every field.
GeoJSONQGIS, ArcGIS, geojson.io and other GIS toolsA point per installation in WGS 84 (EPSG:4326), its fields as properties, plus the export date, who exported it and the filters used.
PDFPrinting, sharing with managementA formatted table with the filters, the generation date, the record count and the installed capacity.

Every export is recorded in the audit trail: who exported, which format and how many records.

Opening the GeoJSON in QGIS

  1. Open QGIS and start a new project.
  2. Layer → Add Layer → Add Vector Layer…, choose the downloaded .geojson file, then Add. Dragging the file onto the map also works.
  3. Add a basemap if you like: in the Browser panel, XYZ Tiles → OpenStreetMap.

Installations without coordinates cannot be placed on a map. They are left out of the GeoJSON and counted in its metadata as skipped_no_coordinates.

Installed capacity in the PDF

The PDF's Installed capacity (operational) counts systems that are built. Awarded and under-construction installations are excluded, and the PDF says how many were left out.
