Troubleshooting and FAQ

Common problems and their fixes, grouped by where they show up.

Signing in

The login code never arrives

  • Check the spam or junk folder.
  • Wait 60 seconds and click to send a new code. Only the newest code works.
  • The mail settings may be wrong. Check MAIL_DRIVER and its keys (Outgoing mail); with Brevo, MAIL_FROM_ADDRESS must be a verified sender. Run scripts/send-test-email.php to test them.
  • On your own computer, APP_ENV=development shows the code on the page when it cannot be emailed.

"Too many incorrect codes" or "Too many codes sent"

The sign-in attempt has ended. Start again from the sign-in page with your password; a new code is sent.

"Too many failed attempts. Account locked for 15 minutes."

Five wrong passwords in a row lock the account. Wait 15 minutes, or ask an administrator to set a new password for you.

"Your account is awaiting administrator approval."

New client accounts need approval. An administrator approves them in Administration → Users → Pending Approval.

"This account has been deactivated."

An administrator turned the account off. Ask them to reactivate it.

I was signed out while working

Sessions end after 30 minutes without activity. A warning appears first; click Stay signed in to continue.

Installation and setup

"could not find driver" or "no pdo_pgsql driver"

PHP cannot talk to PostgreSQL. In C:\xampp\php\php.ini, enable extension=pdo_pgsql and restart Apache. Run commands with XAMPP's PHP (C:\xampp\php\php.exe); another PHP on your computer may not have the driver.

"Could not connect to the database"

  • Is PostgreSQL running? On Windows, check Services for postgresql.
  • Do DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME and DB_PASSWORD in .env match your PostgreSQL? The port is often 5432, but not always.
  • Does the database exist? Create it with CREATE DATABASE solarcore_db;

Migration fails at 001_create_extensions.sql

PostGIS is not installed for your PostgreSQL. On Windows, install it with Stack Builder (Installation, step 1), then run scripts/migrate.php again.

Every page shows "Not Found"

  • Open the right address: http://localhost/solarcore/public/ for XAMPP.
  • If the project folder is not called solarcore, or SolarCORE is on a domain root, set APP_BASE_PATH and APP_URL to match (Configuration).
  • Apache needs mod_rewrite on, and AllowOverride All for the folder. Both are on in a default XAMPP.

The page is blank or shows a PHP error

Run composer install in the project folder; the vendor folder may be missing. Then check Apache's error log (XAMPP Control Panel → Apache → Logs).

The map

"The map could not load" or a grey background

The map's library and background images come from the internet. Check the connection, and that a firewall or ad blocker is not blocking unpkg.com, arcgisonline.com or openstreetmap.org. The data, the list and the forms keep working meanwhile.

An installation is missing from the map

  • A filter may be on. A dot on the Filters button means so; click Reset.
  • For a client: the installation may not be linked to your account yet.

Nearby search says the spatial extension is not set up

PostGIS is not set up on this database. Install it and run scripts/migrate.php. Counts and capacity keep working without it.

Records, photos and imports

"Coordinates fall outside the Philippines"

Latitude and longitude are probably swapped. In the Philippines, latitude is about 5 to 21 and longitude about 116 to 127.

A photo will not upload

Only JPG, PNG and WebP up to 5 MB are accepted. Phone photos in HEIC format must be converted first, or set the phone camera to "Most compatible".

Photos disappeared after a deploy (Railway)

PHOTO_STORAGE_PATH is not on a volume, so photos were saved inside the container and lost when it was rebuilt. Attach a volume, set PHOTO_STORAGE_PATH to it, and restore the photos from a backup.

"Excel files can't be imported directly"

Save the sheet as CSV first: in Excel, File → Save As → CSV UTF-8 (Comma delimited).

Imported rows are marked as duplicates

They match an installation already in SolarCORE, or an earlier row in the same file. If they really are different sites, tick Import anyway on those rows. See Duplicates.

The rest of my file is missing from the review

A cell probably opens a quotation mark (") that never closes, so the rest of the file is read as one cell. That row is marked invalid. Remove the stray quote, save, and upload again.

The assistant

The assistant's answers are short and plain

The AI service is off or unreachable, so built-in rules are answering. Check AI_ENABLED, AI_PROVIDER, AI_MODEL and the key (AI assistant settings). The figures are correct either way.

It says a place is unknown

Only places that appear in the records are recognised. Check the spelling, or ask about the municipality instead of the barangay.

Frequently asked questions

Does SolarCORE need an internet connection?

The system itself runs on the server. Users need a connection for the map backgrounds, email codes, Google sign-in and the AI wording. Everything else works on a local network.

Can it run on shared hosting?

Only if the host offers PostgreSQL with PostGIS, which most shared hosting does not. Use Railway or a virtual machine; see Deployment.

Can clients edit their installations?

No. Clients view their installations and report problems; staff keep the records.

Can SolarCORE be used by another company?

Yes. Change ORG_NAME, ORG_SHORT and ORG_ABOUT, and the map area in config/geo.php.

Is deleted data really gone?

A deleted installation disappears from every page and export, and the deletion is recorded in the audit trail. Accounts are deactivated and archived rather than deleted, so their history is kept.
