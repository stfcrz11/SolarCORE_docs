Getting started

Installation

Set up SolarCORE on a Windows computer with XAMPP, for development, testing or a demonstration. To put it on a server for real use, see Deployment and backups.

Requirements

Access to the code The SolarCORE repository is private. Ask the SolarCORE team for access, or for a copy of the code.

1. Install the software

  1. XAMPP Download it from apachefriends.org, choosing a version with PHP 8.2 or newer. Install it to the default folder, C:\xampp.
  2. PostgreSQL Download the Windows installer from postgresql.org. During setup, choose a password for the postgres user and remember it. Keep the default port, 5432, unless it is already in use.
  3. PostGIS When PostgreSQL finishes, let it start Stack Builder. Pick your PostgreSQL server, then Spatial Extensions → PostGIS, and install it. If you closed Stack Builder, open it from the Start menu.
  4. Composer Download Composer-Setup.exe from getcomposer.org. When it asks for PHP, choose C:\xampp\php\php.exe.

2. Enable the PHP extensions

Open C:\xampp\php\php.ini in a text editor. Find each of these lines and remove the ; at the start, so they read:

extension=curl
extension=fileinfo
extension=mbstring
extension=pdo_pgsql

Save the file, then Stop and Start Apache in the XAMPP Control Panel.

Check it worked In a terminal, C:\xampp\php\php.exe -m should list pdo_pgsql. If you have more than one PHP on your computer, always use XAMPP's (C:\xampp\php\php.exe) for SolarCORE commands.

3. Get the code

Put SolarCORE in XAMPP's web folder, then install its libraries:

cd C:\xampp\htdocs
git clone <repository URL> solarcore
cd solarcore
composer install

The folder must be named solarcore for the default address to work. To use another name or address, see APP_BASE_PATH.

4. Create the database

Open pgAdmin, which comes with PostgreSQL, or psql, and create an empty database:

CREATE DATABASE solarcore_db;

You do not need to create any tables yourself; step 6 does that.

5. Configure

Copy the example settings file:

copy .env.example .env

Open .env and fill in the database lines with your PostgreSQL details:

DB_HOST=localhost
DB_PORT=5432
DB_DATABASE=solarcore_db
DB_USERNAME=postgres
DB_PASSWORD=your-postgres-password

Leave APP_ENV=development for now. Every other setting is explained in Configuration; the defaults are fine for a first run.

Keep .env private .env holds passwords and keys. Never share it, upload it, or add it to Git; the project already tells Git to ignore it.

6. Create the tables

C:\xampp\php\php.exe scripts\migrate.php

This runs every database migration in order and stops at the first error. It is safe to run again: on an up-to-date database it changes nothing. Run it again whenever you update the code.

It lists each file and ends with Done. All migrations applied.

  • If it stops with FAILED at 001_create_extensions.sql, PostGIS is not installed. Go back to step 1, item 3.
  • If it says this PHP has no pdo_pgsql driver, see step 2.
  • If it could not connect, check the DB_* lines in .env and that PostgreSQL is running.

7. Open SolarCORE

With Apache running in XAMPP, open:

http://localhost/solarcore/public/

You should see the SolarCORE home page. Click Log in.

8. First sign-in

  1. Sign in as admin The initial administrator password is shared by the SolarCORE team, not published here.
  2. Set your own password and email SolarCORE asks for a new password (at least 8 characters, different from the initial one) and your real email address.
  3. Enter the code A 6-digit code is sent to that address. In APP_ENV=development, if email is not set up yet, the code is shown on the page instead.
  4. Done The dashboard opens. From now on every sign-in is your password, then a code sent to your email.

9. Next steps

  • Set up email so codes and notifications are sent: Outgoing mail.
  • Set the map's home area and your company's name: Configuration.
  • Create staff accounts: Administrator guide → Users.
  • Add installations one by one, or import a spreadsheet: Import and export.

Updating SolarCORE

cd C:\xampp\htdocs\solarcore
git pull
composer install
C:\xampp\php\php.exe scripts\migrate.php

Running the tests

For developers. Unit tests need no database:

C:\xampp\php\php.exe vendor\bin\phpunit
